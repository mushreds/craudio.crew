# Posts de feed

Os quatro posts de estreia da Craudio Crew, em 4:5 (1080 × 1350), feitos com o molde do componente PostCenario.

| Ordem | Cenário | Frase | Pose |
| --- | --- | --- | --- |
| 1 | Fluido | Eu só escrevo o PROMPT e ele faz o RESTO | Café |
| 2 | Código | Rodou de PRIMEIRA, ninguém MEXE | Notebook |
| 3 | Nuvens | Esperando o RESET com muita CALMA | Travesseiro, com o Limitinho |
| 4 | Folhas | Estourei o LIMITE, fui tocar na GRAMA | Deitada na grama |

Os PNGs prontos para postar ficam em `saida/`.

## Para gerar de novo

```bash
node render.js
```

`index.html` tem os quatro posts; troque frase, pose ou enquadramento (`object-position`) no bloco de cada um e rode o comando de novo.
