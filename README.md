# craudio.crew

Identidade visual da Craudio Crew: a capivara de moletom roxo, o Limitinho e os quatro cenários (Fluido, Folhas, Nuvens e Código).

- **Página do design system:** https://claude.ai/artifact/3sn5diKkNSPcue1xyhgLir
- **Brand book:** [`project/README.md`](project/README.md)
- **Prompts do Flow:** [`project/prompts-e-aplicacoes.md`](project/prompts-e-aplicacoes.md)
- **Cores e fontes:** [`project/tokens.json`](project/tokens.json)

## Como editar de qualquer computador

1. Entre na sua conta do Claude (claude.ai/code ou o app) e abra uma sessão com este repositório.
2. Peça a mudança em linguagem normal, por exemplo "troca o laranja do cenário Nuvens" ou "adiciona essa referência".
3. O Claude altera os arquivos, publica na página do design system e faz o commit aqui. As instruções que ele segue estão em [`CLAUDE.md`](CLAUDE.md).

Se você editar direto na página, peça "sincroniza a página com o repositório" que as mudanças voltam para cá.
