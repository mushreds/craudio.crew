A letra derretida é o recurso que faz a palavra gigante perder corpo conforme o limite acaba, usando o eixo Year da Climate Crisis.

## Níveis

- 1979: letra cheia. É o padrão de toda palavra gigante.
- 2000: começa a derreter. Para piadas de aviso e de "quase lá".
- 2019: o máximo permitido. Ainda se lê de longe no tecido.
- 2050: não usar. A letra fica fina demais para silk e some no preto.

## Regras

- Derreta uma palavra por estampa, e só quando o derretimento é a piada.
- A outra palavra gigante fica em 1979, para o contraste aparecer.
- Conectores em Baloo 2 nunca derretem.
- No editor: instale a fonte variável e mova o controle Year. Em CSS: `font-variation-settings: "YEAR" 2000`.
