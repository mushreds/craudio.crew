O cenário Código é o modo terminal: o código virando uma onda, para quem vive no editor e no terminal.

## Quando usar

- Frases de dev e de bug: "Rodou de primeira, ninguém mexe", "Funcionou e eu não sei por quê".
- Linha "modo terminal" da coleção, lançamentos e conteúdo técnico.
- É o único cenário que usa a fonte `pixel` (Silkscreen), só em etiquetas curtas.

## Versão viva oficial

Gerada no Flow na v3: `assets/Cenarios/vivo-codigo.jpg`. É ela que vai em post, story, wallpaper e deskmat; o desenho em código deste componente fica só como guia de construção.

- Refeita na v3 com o prompt sem códigos de cor: a onda é feita só de colchetes, pontos e traços, sem letra, número ou código legível. Vale para qualquer tamanho.

## Construção

- Chão em `fundo`. Linhas de pseudocódigo em `micro` (JetBrains Mono), seguindo ondas que cruzam o quadro.
- Cores das linhas em rodízio: `roxo-claro`, `laranja`, `tinta-suave`. Opacidade entre 55% e 85% para criar profundidade.
- Pixels soltos em `roxo` (quadrados de 14px) e um cursor em `laranja`.
- O código é inventado e fala a língua da marca: `capivara.cafe(++)`, `limite.resetar()`, `grama.tocar(pata)`.

## Texto por cima

- Conectores em `tinta`, palavras gigantes em `roxo-claro`.
- Placa da cor do chão, `radius-lg`.

## O que nunca fazer

- Usar logo, asterisco, ícone ou nome de qualquer empresa de IA como enfeite da onda.
- Desenhar o bichinho pixel laranja que é mascote de ferramenta de IA. O pixel aqui é só quadradinho solto e cursor.
