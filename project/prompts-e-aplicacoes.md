# Prompts e aplicações

Prompts prontos para o Google Flow (Nano Banana) e a lista de peças e assets da marca. Atualizado na v2 com os quatro cenários (seção 2b) e na v3 com a variante Gloss do Fluido. Os prompts ficam em inglês porque o modelo segue melhor; o texto das estampas entra depois, no editor, com as fontes instaladas.

Ordem de produção: folha de personagem, depois assets, depois mockups. A folha aprovada vira a referência anexada em todos os outros prompts, para a capivara sair sempre igual.

## 1. Folha de personagem da capivara

Anexe um print do componente Capivara deste sistema como Image 1. Proporção 16:9, gere 4 variações e escolha uma só como oficial.

```
TASK
Create a professional character model sheet for an original brand mascot, using Image 1 only as a rough construction guide for proportions and color placement. Redraw it as a polished, final illustration.

CHARACTER
A chubby, calm capybara wearing an oversized purple hoodie with the hood down and two off-white drawstrings. Blocky rounded head, squared darker snout, tiny round ears, small nostril dot, short stubby legs. Default expression: eyes closed in a relaxed downward arc, subtle half-smile, completely unbothered. Personality: a sleepy, content office worker who lets the computer do the work.

SHEET LAYOUT
Top row, three full-body turnaround views, evenly spaced, same scale: front view, 3/4 view facing right, side profile facing right.
Bottom row, five head-and-shoulders expressions: calm (eyes closed, half-smile), asleep (straight-line eyes, small "z" shapes), mildly worried (one open eye looking sideways, one sweat drop), pleased (eyes closed, wider smile), sipping coffee from a plain off-white mug.
Right column, three small action poses: typing on a generic laptop with no logo, lying on grass looking at the sky, hugging a pillow.

STYLE DNA
Medium & style: flat vector cartoon mascot illustration, sticker and screen-print ready, cute but not childish.
Line: thick uniform black outline of constant weight, clean confident curves, rounded line ends.
Fill: flat solid colors only, one slightly darker flat tone for minimal cel shading, no gradients, no texture, no highlights except tiny off-white eye glints.
Color palette, use only these: fur vivid orange #FF7A1A, snout/ears/paws darker orange #C9560A, hoodie lilac purple #8B6CF5, drawstrings and objects off-white #F1ECE4, outline black #000000.
Background: flat deep purple #2A0F5C, so the black outline stays visible. Generous even spacing between figures.
Consistency: identical proportions, colors and outline weight in every view.

OUTPUT
16:9, high resolution, character sheet. No words, letters, labels, logos or watermarks anywhere in the image.
```

Ajustes rápidos:

```
Keep everything identical. Make the outline weight exactly the same on every figure.
Keep everything identical. Use only the five listed colors; remove any brown, pink or gray.
Keep everything identical. Remove all text and labels from the sheet.
```

### Fundo fluido

Anexe uma das referências de fluido como Image 1. Só para uso digital e impressão em sublimação; não vai em silk.

```
TASK
Create an abstract liquid background matching the style of Image 1: thick, glossy, slow-flowing paint in wavy bands.

STYLE DNA
Medium: 3D render of viscous glossy liquid, smooth swirling folds, soft studio reflections, a few round droplets and one or two thin drips.
Color palette, only these: vivid orange #FF7A1A, lilac purple #8B6CF5, vivid purple #6A2FE0, deep purple #2A0F5C, with small off-white #F1ECE4 specular highlights. Roughly half orange, half purple.

9:16, high resolution, seamless feel at the edges. No text, no characters, no logos.
```

Versão chapada para estampa (referência das manchas roxas e laranja): troque STYLE DNA por `flat 2-color vector blobs, organic melting shapes with a few radiating rays, no gradients, no shading, orange #FF7A1A on deep purple #2A0F5C`.

## 2b. Os quatro cenários (novo na v2)

Gere a versão viva de cada cenário no Flow. Anexe a referência indicada (em Referências, nos assets) como Image 1. Proporção 9:16 para story e wallpaper; refaça em 4:5 para post e 16:9 para deskmat. A versão chapada é desenhada depois, em vetor, a partir da viva aprovada.

Regra para todos: nada de texto, letra, logo, asterisco ou personagem na imagem. O cenário é só o mundo; capivara e frase entram depois, no editor.

### Fluido (trabalho e fluxo)

Image 1: `ref-fluido-a1.jpg`.

```
TASK
Create an abstract background in the style of Image 1: thick, slow, marbled liquid paint flowing in wide curved bands.

STYLE DNA
Medium: digital painting of viscous swirling liquid, fine streaks inside each band, soft glossy sheen.
Color palette, only these: deep purple #2A0F5C as the base, vivid purple #6A2FE0, lilac #8B6CF5 and light lilac #B8A4FF in the bands. One single fiery stream crossing the frame in burnt orange #E8480C, orange #FF7A1A and a thin peach #FFC79A core.
Composition: the fiery stream enters from the lower left and exits upper right, about 25% of the area. Keep a calmer, darker zone in the lower third for text and a character.
Lighting: soft, no harsh glare.

OUTPUT
9:16, high resolution, edges that feel continuous. No text, no letters, no logos, no characters.
```

### Fluido Gloss (novo na v3)

Image 1: `ref-tubos-a3.jpg`. Só para digital e sublimação.

```
TASK
Create an abstract background in the style of Image 1: thick glossy 3D tubes looping and knotting over each other, filling the whole frame.

STYLE DNA
Medium: 3D render, smooth glass-like plastic tubes, soft studio reflections, gentle ambient occlusion where tubes overlap.
Color palette, only these: tubes in vivid purple #6A2FE0 and lilac #8B6CF5, shadows in deep purple #2A0F5C, highlights in light lilac #B8A4FF with thin off-white #F1ECE4 specular lines. Exactly one tube in orange #FF7A1A crossing the frame. No blue, no cyan, no pink reflections.
Composition: tubes bleed off every edge, large scale (each tube about 15% of the frame width). Slightly less dense in the lower third for text.
Lighting: large soft light from the upper left.

OUTPUT
9:16, high resolution. No text, no letters, no logos, no characters.
```

### Código (modo terminal)

Sem referência anexada: as referências de código que vieram tinham marca de terceiros. Este prompt já descreve o estilo.

```
TASK
Create a dark background where lines of monospaced code flow across the frame like a big ocean wave.

STYLE DNA
Medium: digital illustration, crisp monospaced characters following curved paths, slight glow on the brightest lines, depth created by opacity (far lines dimmer and smaller).
Color palette, only these: background near-black purple #1A0838, code lines in light lilac #B8A4FF, orange #FF7A1A and soft lavender #CFC6EA, a few loose square pixels in lilac #8B6CF5, one orange text cursor block.
Composition: the wave curls from the left edge toward the upper right. Keep the lower third calmer for text.
Content: the code is unreadable at a glance. No real brand names, no logos, no symbols of any company, no mascots.

OUTPUT
9:16, high resolution. No readable words, no logos, no characters.
```

Ajuste para o Código (a primeira geração escreveu os códigos de cor como texto). Use no mesmo chat do Flow, com a imagem gerada:

```
Keep everything identical: the wave shape, colors, glow and composition. Replace every readable string, especially hex color codes like #FF7A1A, #CFC6EA or #B8A4FF and any English words, with meaningless monospaced symbols and short fake code fragments. Nothing in the image should be readable as a word or a color code.
```

Ajustes rápidos:

```
Keep everything identical. Use only the listed hex colors; remove any blue, pink or green.
Keep everything identical. Remove any text, letters, logos or symbols.
Keep everything identical. Make the lower third calmer and less detailed.
```

## Cuidados

- Sempre "generic laptop, no logo": nada de marca de terceiros na cena.
- Pessoas sempre de costas ou sem rosto visível.
- O texto da arte nunca é gerado pelo modelo. Se sair letra errada, o problema é a arte anexada, não o prompt.
